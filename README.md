## 📖 אודות הפרויקט (Project Overview)

מאגר זה מהווה את **אוסף משחקי הרטרו והארקייד המקיף והעשיר ביותר שנוצר עבור מערכת ההפעלה LG webOS** בטלוויזיות חכמות (LG OLED, QNED, NanoCell ו-UHD).

כל המשחקים עברו התאמה ארכיטקטונית מלאה לרזולוציית מסך סלוני (**1080p ו-4K 60FPS**), עברות ממשקים וכיתובים לשפה העברית, אינטגרציה קולית עם מנועי Web Audio סינתטיים מובנים (ללא תלות בספריות צד שלישי), ותמיכה אינטואיטיבית בשלט **LG Magic Remote** (שימוש בפוינטר ובגלגלת) ובחיצי ה-**D-Pad** הפיזיים.

המערכת כוללת בנוסף את **Retro Cloud Arcade (v3.0.0)** — רכזת משחקים אחודה (Master Hub) עם מנוע משיכה וסנכרון ישיר מה-Cloud של GitHub המאפשר לשחק אונליין, לטעון שלבים ותוכן דינמי, ובו-בזמן לפעול באופן עצמאי ומיידי (Offline Fallback) ללא חיבור רשת!

## 🌟 תכונות מפתח (Key Features)

* **16 משחקי רטרו מלאים:** החל מלהיטי DOS ו-id Software ועד קלאסיקות פלאש, נינטנדו וארקייד של שנות ה-80 וה-90.
* **ענן והורדה מקוונת (GitHub Cloud Sync):** משיכה ישירה של משחקים, חבילות שלבים ותוכן מה-GitHub Repository עם תמיכה מלאה במשחק אונליין ובמצב מקומי מהיר.
* **תמיכה מלאה בשלטי LG Magic Remote:** מתיחת רוגטקה ב-Angry Birds Rio, חיתוך חבלים מדויק ב-Cut the Rope, ירי אקדח אור (Light Gun) ב-Duck Hunt, ומשחקיות פלאפי בירד בקליק אחד.
* **עברות מלא (Hebrew UI & Fonts):** תפריטים, הוראות, מקשים, שלבים ולוחות ניקוד בעברית מלאה וישרה (RTL Native).
* **אופטימיזציה ייעודית לחומרת LG TV:** שימוש ברינדור חומרתי מואץ GPU דרך Canvas 2D ו-WebGL, עם זמני טעינה אפסיים וצריכת זיכרון מינימלית.
* **שתי דרכי התקנה לבחירה:**
  1. **ארקייד נוסטלגיה (Master Hub IPK):** חבילה אחת שלמה שמרכזת את כל 16 המשחקים בממשק טלוויזיוני עתידני.
  2. **חבילות IPK בודדות (Standalone):** כל משחק זמין גם כקובץ IPK נפרד להוספה ישירה לשורת האפליקציות הביתית של ה-webOS.

### 🦜 1. Angry Birds Rio (מהדורת ריו דה ז'ניירו HD)
* **רקע:** גרסת הקולנוע המפורסמת שפותחה בשיתוף עם אולפני Fox. הפעם המטרה אינה רק לפגוע בחזירים, אלא לנפץ כלובים ולשחרר את התוכים האקזוטיים בלו וג'ול (Blu & Jewel) שנחטפו בריו דה ז'ניירו!
* **שליטה בשלט LG:** לחץ עם סמן הפוינטר על הרוגטקה, משוך לאחור לכיוון העוצמה והזווית, ושחרר כדי לשגר את הציפור. כולל אפקטי נוצות וצלילי סמבה בסינתזה מלאה.

### 🍬 2. Cut the Rope (חתוך את החבל)
* **רקע:** אחד ממשחקי המיומנות הפיזיקליים המצליחים בכל הזמנים. המטרה היא להאכיל את המפלצת הירוקה והחמודה **Om Nom** בסוכריות מתנדנדות תוך איסוף 3 כוכבים זהובים בכל שלב.
* **שליטה בשלט LG:** השתמש בסמן ה-Magic Remote כמו להב חד — חתוך חבלים על ידי גרירת הסמן על פני המסך וצפה בסוכרייה נופלת היישר לפיו של Om Nom!

### 🦆 3. Duck Hunt (דאק האנט — צייד הברווזים של נינטנדו)
* **רקע:** קלאסיקת ה-NES המיתולוגית משנת 1984! בעבר נדרש אקדח ה-NES Zapper המקורי כדי לירות בברווזים הממריאים מהעשב; כעת, שלט ה-Magic Remote של LG הופך לאקדח אור מודרני, מדויק ומהיר.
* **שליטה בשלט LG:** כוון את סמן הפוינטר על הברווז המעופף ולחץ על כפתור **אישור (OK / Scroll Click)** כדי לירות. היזהר שלא להחמיץ פן הכלב הנוסטלגי יצחק עליך!

### 🐥 4. פלאפי בירד 4K (Flappy Bird)
* **רקע:** תופעת הרשת ששיגעה את העולם בשנת 2013, מרונדרת כעת בחדות 4K מרהיבה עם עננים, שמיים וצינורות גראפיים חלקים.
* **שליטה בשלט LG:** לחיצה אחת על הפוינטר או על כפתור אישור (OK) בשלט גורמת לציפור לנופף בכנפיה ולהתרומם. תזמן את המעברים בין הצינורות הירוקים ושבור את שיא הניקוד המקומי הנשמר בטלוויזיה.

### 🍄 5. סופר מריו קלאסי (Super Mario Bros)
* **רקע:** עולם 1-1 האגדי משוחזר בדיוק מוחלט של 60 פריימים לשנייה. כולל גומבות, צבים (Koopas), קוביות מסתוריות עם סימני שאלה, פטריות גדילה, מטבעות מוזהבים ודגל הסיום המפורסם.
* **שליטה בשלט LG:** חץ ימינה/שמאלה לריצה, כפתור אישור (OK) לקפיצה ולמעיכת אויבים.

### 💀 6. דום קלאסי בעברית (DOOM 1.9)
* **רקע:** משחק היריות התלת-מימדי המהפכני של ג'ון קארמק וג'ון רומרו. המנוע מריץ את קובץ ה-`DOOM1.WAD` המקורי מגרסה 1.9, עם ממשק סטטוס (תחמושת, בריאות, שריון ונשקים) בעברית צחה.
* **שליטה בשלט LG:** חיצי למעלה/למטה לתנועה, ימינה/שמאלה לסיבוב מבט, מקש אישור (OK) לירי ברובה.

### 🏰 7. וולפנשטיין 3D בעברית (Wolfenstein 3D)
* **רקע:** אב הטיפוס של משחקי היריות בגוף ראשון. בריחה ממעמקי טירת וולפנשטיין באמצעות מנוע Raycasting מהיר במיוחד המותאם למעבדי ה-ARM של LG.
* **שליטה בשלט LG:** חיצי כיוון לניווט במסדרונות, מקש אישור לירי באקדח ואיסוף תיבות אוצרות.

### 🧢 8. דייב המסוכן בעברית (Dangerous Dave)
* **רקע:** משחק הילדות שכל ישראלי שיחק בו בחדרי המחשבים של בתי הספר בשנות ה-90. דייב צריך לאסוף את הגביע הנוצץ, להשתמש בג'טפאק כדי לרחף מעל להבות, ולחמוק ממפלצות יורקות אש לעבר דלת השלב הבא.
* **שליטה בשלט LG:** חיצים לריצה, מקש אישור לקפיצה.

### 🛸 9. אייר-קסוניקס 3D בעברית (AirXonix)
* **רקע:** גרסת תלת-מימד מרהיבה למשחק ה-Xonix המפורסם. שלוט ברחפן עתידני מעל זירה מרחפת בחלל, חתוך פסים ובנה בלוקים מוגבהים תוך התחמקות מכדורי הרפאים המקפצים.
* **שליטה בשלט LG:** חיצי ה-D-Pad מנווטים את הרחפן בדיוק מרבי.

### 🟡 10. פאק-סוניקס בעברית (Pac-Xon)
* **רקע:** השילוב המושלם בין פאק-מן לקסוניקס! כבוש 80% מהלוח כדי לעבור שלב, אסוף בונוסים של בננות להקפאת רוחות ונעליים להגברת מהירות, והיזהר שהרוחות לא ייגעו בשובל שאתה משאיר.
* **שליטה בשלט LG:** חיצי השלט שולטים בכיוון התנועה של פאק-מן.

### 🍒 11. פאק-מן 1980 קלאסי (Pac-Man Namco Arcade)
* **רקע:** מכונת הארקייד הרווחית ביותר בהיסטוריה. המבוך הכחול המקורי, נקודות האור, גלולות הכוח (Power Pellets) שהופכות את הרוחות (בלינקי, פינקי, אינקי וקלייד) לכחולות ופגיעות, וצלילי ה-Waka-Waka האהובים.
* **שליטה בשלט LG:** חיצי ה-D-Pad משנים את כיוון הפנייה של פאק-מן בצמתים.

### 👾 12. פולשים מהחלל (Space Invaders 1978)
* **רקע:** משחק היריות שיצר את תור הזהב של משחקי הווידאו. ארמדת חייזרים היורדת מטה בשורות מסודרות, מחסי בונקר ירוקים הנסדקים תחת פגיעות לייזר, ותותח קרקעי המגן על כדור הארץ.
* **שליטה בשלט LG:** חיצים שמאלה/ימינה להזזת התותח, מקש אישור (OK) לשיגור לייזר.

## 🚀 4 דרכים קלות להתקנה על הטלוויזיה (Installation Methods)

### שיטה 1: התקנה מהירה ואוטומטית באמצעות סקריפט (מומלץ)
אם הטלוויזיה שלך מחוברת ל-Wi-Fi הביתי ומצב מפתח (Developer Mode) מופעל בה:
```powershell
# הרצת סקריפט הפריסה האוטומטי עבור חבילת הארקייד הראשית
python deploy_to_tv.py packages/com.retrohub.nostalgia_3.0.0_all.ipk com.retrohub.nostalgia

# או התקנת Angry Birds Rio כמשחק עצמאי
python deploy_to_tv.py packages/com.rovio.angrybirdsrio_1.0.0_all.ipk com.rovio.angrybirdsrio
```

### שיטה 2: התקנה קלה דרך תוכנת המחשב webOS Dev Manager (ממשק גרפי)
1. הורד את תוכנת [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop/releases) למחשב שלך.
2. חבר את התוכנה לטלוויזיה באמצעות כתובת ה-IP ומפתח ה-SSH מאפליקציית Developer Mode בטלוויזיה.
3. לחץ על כפתור **Install** וגרור את קובץ ה-`.ipk` שהורדת מטבלת ההורדות למעלה.
4. תוך מספר שניות האפליקציה תופיע במסך הבית של הטלוויזיה!

### שיטה 3: התקנה דרך שורת הפקודה הרשמית של LG (webOS CLI)
```bash
# הוספת הטלוויזיה להגדרות ה-CLI
ares-setup-device -a MyTV -i 192.168.1.5 -p 9922 -u prisoner

# התקנת קובץ ה-IPK
ares-install -d MyTV packages/com.retrohub.nostalgia_3.0.0_all.ipk
```

### שיטה 4: הפעלה ישירה אונליין בדפדפן הטלוויזיה (ללא צורך בהתקנה!)
* פתח את אפליקציית **דפדפן האינטרנט (Web Browser)** המובנית בטלוויזיה שלך.
* היכנס ישירות לכתובת ה-Cloud של הפרויקט:
  `https://dor2500.github.io/webos-tv-games/`
* כל 16 המשחקים יטענו ישירות מהענן וניתנים למשחק מיידי עם שלט ה-Magic Remote!

## ⚡ מדריך אופטימיזציה ושיפור ביצועים ל-LG webOS (Deep Debloat Guide)

לטלוויזיות LG webOS יש מעבד ייעודי וזיכרון RAM מוגבל (בדרך כלל 1.5GB עד 2.5GB). כדי להבטיח ביצועי גיימינג חלקים ב-60 פריימים לשנייה ללא תקיעות, מומלץ לבצע את ההתאמות הבאות:

1. **ביטול איסוף נתונים ושירותי Live Plus:**
   * היכנס לתפריט: **הגדרות (Settings) -> כל ההגדרות -> כללי (General) -> הגדרות נוספות (Additional Settings)**.
   * כבה את האפשרויות: **Live Plus**, **פרסום מותאם אישית (Personalized Advertising)** ו-**שיתוף נתוני צפייה (Viewing Information)**. ביטול שירותים אלו משחרר תהליכי רקע כבדים של סריקת תוכן המסך בזמן אמת.
2. **הפעלת מצב תגובה מהירה למשחקים (Game Optimizer / ALLM):**
   * ודא שפונקציית **Game Optimizer** או **Instant Game Response** פעילה בכניסה או בעת הפעלת אפליקציות גיימינג. זה מקטין את ה-Input Lag למינימום האפשרי (פחות מ-10 מילי-שניות ב-OLED!).
3. **הארכת משך ה-Developer Mode (Keep-Alive):**
   * Developer Mode רשמי של LG מוגבל כברירת מחדל ל-50 שעות פעילות לפני שהוא דורש חידוש.
   * באפליקציית Developer Mode בטלוויזיה, אפשר את מתג **Key Server** וודא חיבור לחשבון מפתח חינמי. סקריפט רקע פשוט יכול לשלוח פינג קבוע לחידוש הטיימר.
4. **ניקוי זיכרון RAM מהיר דרך השלט:**
   * לחיצה ארוכה על כפתור **Home (הבית)** או כפתור ה-**Back** מאפשרת סגירת כל אפליקציות הרקע הפתוחות המעמיסות על הזיכרון.

## 🛠️ ארכיטקטורת המערכת ומבנה חבילות ה-IPK

כל קובץ `.ipk` הוא למעשה ארכיון מסוג **Debian Binary (ar archive)** התואם למערכת ניהול החבילות של webOS (נגזרת של opkg).

📦 Package: com.retrohub.nostalgia_3.0.0_all.ipk
├── 📄 debian-binary               # הגדרת גרסת פורמט (2.0)
├── 📦 control.tar.gz              # מטא-דאטה למנהל החבילות
│   └── 📄 control                 # Package ID, Version, Architecture: all, Maintainer
└── 📦 data.tar.gz                 # קבצי האפליקציה המותקנים למערכת
    └── 📂 usr/palm/applications/com.retrohub.nostalgia/
        ├── 📄 appinfo.json        # תעודת זהות של האפליקציה ב-webOS
        ├── 📄 index.html          # מנוע ה-Hub וסנכרון הענן
        ├── 🖼️ icon.png            # אייקון לשורת האפליקציות (130x130)
        ├── 🖼️ largeIcon.png       # אייקון מוגדל באיכות גבוהה (130x130)
        ├── 🖼️ splash.png          # תמונת פתיחה למסך מלא (1920x1080)
        └── 📂 games/              # 16 מנועי המשחקים בנפרד
            ├── 📂 angrybirds_rio/

            ├── 📂 duckhunt/
            ├── 📂 flappybird/
