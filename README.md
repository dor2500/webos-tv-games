## 📖 אודות הפרויקט (Project Overview)

פרויקט זה נבנה **מחדש לחלוטין מאפס** כדי לספק את חוויית הארקייד האותנטית, המקורית והמקצועית ביותר לטלוויזיות חכמות LG webOS ולדפדפן.

### 🌟 עקרונות הארכיטקטורה החדשה (v6.0.0):
1. **אפס משחקי דמה (Zero Dummy Games):** נמחקו כליל כל משחקי המוקאפ וה-Canvas הקטנים. כל משחק במאגר מופעל על גבי המנוע המקורי הרשמי שלו וקובצי הבינארי המקוריים שלו (קובצי WAD מקוריים של id Software, מנוע WASM של סגה, מנוע המשחק הרשמי של Rovio וכו').
2. **מסך טעינה אותנטי (Authentic Asset Loading HUD):** לפני תחילת כל משחק מוצג מסך טעינה מהפנט עם מד התקדמות (0% עד 100%), טעינת נכסים אמיתית ושלבי אתחול ברורים.
3. **הפעלה כפולה — Native TV App & Web Arcade:** הפעלת המשחקים כמערכת ייעודית מקומית ב-webOS TV או הרצה ישירה בתוך מסגרת הארקייד.
4. **פרטיות מוחלטת (100% Sanitized):** המאגר אינו מכיל כתובות IP אישיות, מפתחות SSH או פרטים מזהים. כל הסקריפטים תומכים בקלט דינמי מלא.

## 🚀 הורדה והתקנה על גבי הטלוויזיה (Installation Guide)

### אפשרות א': התקנה ישירה בלחיצה אחת (PowerShell)
```powershell
# הרצת סקריפט ההתקנה (מבקש את כתובת ה-IP של הטלוויזיה באופן דינמי)
.\install-to-tv.ps1
```
או עם כתובת IP ישירה:
```powershell
.\install-to-tv.ps1 -TvIp 192.168.X.X
```

### אפשרות ב': התקנה באמצעות סקריפט Python
```bash
python deploy_to_tv.py packages/com.retrohub.nostalgia_6.0.0_all.ipk com.retrohub.nostalgia 192.168.X.X
```

### אפשרות ג': התקנה גרפית דרך webOS Dev Manager
1. הורידו את החבילה העדכנית מדף ה-[Releases](https://github.com/dor2500/webos-tv-games/releases).
2. פתחו את תוכנת **webOS Dev Manager**.
3. לחצו על **Install** וגררו את הקובץ `com.retrohub.nostalgia_6.0.0_all.ipk`.
4. האפליקציה תופיע מיד בסרגל האפליקציות הראשי של הטלוויזיה.
